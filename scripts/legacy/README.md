# 과거 배포 도구

이 디렉터리는 이전 클라우드 구성·마이그레이션 코드를 보존한 기록이다.
현재 운영 배포는 `scripts/token_connection_release.py`, 토큰 변경은
`change-access-token.command`를 사용한다.

과거 스크립트는 당시의 비공개 `.local` 증빙과 이미 종료한 웹앱 빌드 파일을
참조할 수 있다. 현재 운영에 그대로 실행하지 않는다. 원문·수집·분석·보고의
현재 구현은 `sns_comment/`에 있으며, 웹 화면 및 웹앱 배포 도구는 제거했다.

특히 `cloud_setup.py`의 `update-meta`, 초기 배포·예약 활성화 명령은 과거
초기화용이다. 현재 토큰 변경 절차와 검증을 대체하지 않는다.
