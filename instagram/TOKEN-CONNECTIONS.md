# 토큰·계정 연결

macOS는 `change-access-token.command`, Windows는 `change-access-token.bat`을 사용한다.
토큰은 숨김 입력하며 채팅·명령 인수·환경 파일에 적지 않는다. 활성 회사 Google
계정에 `sns-meta-token`, 상태 버킷, `sns-comments-moderate` 실행 권한이 필요하다.
명시 계정은 `--account 이메일` 또는 `SNS_GCLOUD_ACCOUNT`로 지정한다.

| 명령 | 동작 |
| --- | --- |
| 실행 파일 기본 실행 | 토큰 검증·계정/지역 연결 저장 후 댓글 관리 Job 시작 |
| `--check` | 현재 토큰과 계정·게시물·댓글 읽기 검증, 저장·실행 없음 |
| `--status` | 현재 연결과 댓글 관리 작업의 연결 확인 상태 조회 |
| `--no-wait` | 검증·저장·댓글 관리 실행 후 대기하지 않고 종료 |
| `--adopt-current` | 기존 토큰을 유지한 채 연결만 등록 |

새 계정의 지역명은 처음 한 번 지정한다. 계정 ID와 원본 경로·검수 이력은 유지하고
이전 계정을 새 계정의 원문으로 바꾸지 않는다. 원본 시트 투영과 SNS Comments
보고는 2026-11-17부터 종료했으며 토큰 변경으로 다시 시작하지 않는다.

등록부는 `web/registry.json`, 연결 상태는 `connections/status.json`에 보관한다.
저장 직후 `sns-comments-moderate`를 실행하고, 작업이 같은 연결 버전을 읽었는지
확인한다. 대기 댓글과 긴 게시물 순회는 이후 30분 작업에서도 이어간다. `ready`는
계정 연결이 확인됐다는 뜻이며 모든 게시물 순회·시트·Notion 완료를 뜻하지 않는다.
`--status`에 과거 시트·노션 전달 자료가 남아 있으면 과거 형식의 이력으로 표시한다.
