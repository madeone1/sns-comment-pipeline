수집 완료 후 첫 재실행(youtube-comments-daily-9bvxj)에서 ID 검사 오류가 1회 발생했고
자동 재시도로 복구했다. 사후 시트와 DB를 전수 대조해 실제 고유 ID 35,199개와 행 매핑의
일치를 확인했다. 실제 시트 정렬 순서는 초기 저장 순서와 달라져 있었다.
정렬 중 여러 차례의 ID 조회가 서로 다른 행 순서를 관측할 가능성을 줄이도록
ID열을 한 응답으로 조회하게 보완했으며 최종 예약 호출과 전체 셀 대조를 다시 통과했다.
최초 오류의 정확한 동시 편집 순서는 확인하지 않았다.

시트 전송만 실패해도 다음 호출에서 복구하도록 수집 완료 날짜에도 시트 상태를 대조한다.
변경되지 않은 댓글 행은 다시 쓰지 않는다. 중복 ID가 실제로 존재하면 덮어쓰기를 중단한다.
비공개 최종 증빙은 .local/youtube-pipeline-release/final-verification.json에 보관한다.

## 자동 검증과 운영 제한

신규 테스트 35개 통과. 중단 후 재개, 동일 ID 반복·사용자 정렬, 중복 원격 ID 거부,
원문 수식 방지, 예산 유지, 페이지 트랜잭션 롤백, 전역 할당량 오류 즉시 중단 및 재개,
수집 완료 후 시트 전송 실패의 재실행 복구, 로컬 OAuth 세션·일회성 상태·교차 사이트 요청 거부를 확인했다.
기존 파이프라인 테스트는 앞선 점검에서 414개 통과했으며 기존 추적 파일 변경은 없다.

OAuth 앱은 현재 Testing 상태라 refresh token의 7일 제한이 적용된다.
장기 무인 운영을 위해 실제 Branding 정보와 게시·검증 요건을 정리하고 재인증해야 한다.
[Google 공식 설명](https://developers.google.com/identity/protocols/oauth2#expiration).

원본 API 응답과 SQLite, 인증정보는 Git 제외된 .local/youtube-validation 아래에 보관하며
클라우드에서는 전용 비공개 버킷과 Secret을 사용한다. 코드·실행 방법은 [PIPELINE.md](PIPELINE.md).
